# Small Residential Construction Assets

Generated July 8, 2026 for Fairlend construction-financing marketing visuals.

These variants are based on a compact modern urban residential reference photo and matched to the existing monochrome architectural construction-sketch UI style. They intentionally avoid large commercial jobsite cues such as tower cranes, heavy equipment, podium construction, and high-rise framing.

Use the `.webp` files for frontend rendering. Keep the `.png` files as higher-fidelity source exports.

COMPARISON METHOD

One project, two draw strategies.

The model holds project costs, dates, rate, horizon, working capital and review lag constant. Only the draw strategy changes.

  1. Eligibility first. Work must be completed before it can be reimbursed.
  2. Interest after release. Undrawn and merely approved funds do not accrue interest.
  3. Total cost is the headline. Interest and draw fees are shown together.
  4. Infeasibility is visible. The model never silently adds borrower cash.

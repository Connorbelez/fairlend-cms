# FairLend agent-assisted origination prototype

Static HTML/CSS/JavaScript prototype of the user-owned construction intake path described in `docs/architecture/fairlend-agent-assisted-origination.md`.

Open `index.html` directly or serve this directory with any static file server. The flow covers anonymous estimation, secure account claim, field provenance, missing-item completion, explicit approval for indicative pricing, consultation booking, and submission for licensed human review.

The prototype intentionally excludes credit pulls, lender submission, pre-approval issuance, commitment acceptance, signatures, and document upload content. It uses relative assets and has no backend dependency.

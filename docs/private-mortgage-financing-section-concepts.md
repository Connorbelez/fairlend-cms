# Private Mortgage Financing — Section Concepts

## Creative premise

**The deadline file.** The page is a single private-mortgage case file moving from pressure to a defensible exit. It is not a stack of legacy marketing modules. Each section is a different physical artifact inside the same underwriting dossier: cover sheet, incident board, cost X-ray, route map, judgment desk, and question register.

The visual contract is 90% paper plus monochrome halftone ink and 10% lime annotation. Lime encodes only live decisions, routes, verification, and conversion.

## 1. Cover sheet — “Open the file”

- Full-height Toronto halftone field with a decisive serif thesis.
- The existing `FairlendLeadIntake` is the only preserved page component and sits as the literal live file.
- A lime route crosses the skyline from the deadline statement to the intake.
- Four underwriting questions replace a conventional feature strip.

## 2. Incident board — “What forced the decision?”

- Borrower situations become eight incoming case signals pinned to one vertical pressure axis.
- No card grid: each signal is a ruled case row with the borrower’s language, the actual scenario, and the review focus.
- A monochrome private-house engraving occupies the unused field as evidence, not decoration.

## 3. Cost X-ray — “A fast yes can hide a bad structure”

- A black light-table section exposes rushed terms against FairLend’s clear-plan counterpart.
- The total-cost equation runs as a single illuminated lime annotation.
- Six paired rows make the tradeoff legible without alarmist red or generic benefit cards.

## 4. Exit route — “Underwrite backward from maturity”

- The process is a continuous topographic route, not five process cards.
- The route starts with the situation and ends after funding, while a larger exit marker sits before commitment to make the strategy explicit.
- Copy alternates around the route at desktop and linearizes cleanly on mobile.

## 5. Judgment desk — “What the file is actually reviewed against”

- A halftone broker/desk field sits behind a precise four-part review register: borrower, property, mortgage position, and exit.
- Proof is expressed as operating standards rather than unsupported vanity metrics.
- Three verification stamps identify connected review, visible tradeoffs, and professional judgment.

## 6. Question register — “Ask the hard questions before signing”

- A map-led two-column question index uses the existing ShadCN accordion primitive.
- The risk/approval disclaimer is structurally prominent, not buried as legal microcopy.
- The final action routes back to the preserved intake rather than introducing a second competing form.

## Responsive direction

- Desktop uses a single continuous rail with asymmetric art direction and large image fields.
- Tablet collapses sticky/art-directed pairs into stacked dossier artifacts.
- Mobile keeps one recognizable image subject per section, converts dense ledgers into labeled records, preserves 44px targets, and never horizontally scrolls.

CTA Map

Behavior

Single dominant lime CTA. One-action rule — no secondary CTAs. Builder Consulting keeps its own "RUN MY NUMBERS" downstream; they don't compete.

Audience captured

Property owners, buyers, builders, and developers with a property, plan, or early build intent. Lowers the threshold to engage before the visitor has all answers.

Destination

/intake?intent=consultation&source=build-model-consultation

Mobile Priority

  1. Kicker, headline, and subheadline.
  2. Primary CTA ("Book a free consultation") + microcopy.
  3. The four accordion pillars in order: Plan → Finance → Build support → Takeout. First pillar open by default to model the interaction; tap-to-expand reveals sub-services.
  4. The complimentary payoff line.
  5. Transition sentence into the builder equation.

Accessibility Notes

  • Semantic <section aria-labelledby="fairlend-build-model-title"> tied to the headline.
  • Use native <details> / <summary> for pillars — free keyboard, focus, and screen-reader support; the custom chevron is aria-hidden.
  • CTA is a real <a> with accessible name "Book a free consultation" and a visible focus ring.
  • Blueprint line motifs / route lines are decorative: aria-hidden="true", role="img" omitted, never convey meaning alone.
  • Lime is background/accent only — never small body text on paper (contrast). Pillar numbers in orange pass contrast at the locked sizes.
  • Respect prefers-reduced-motion: any chevron rotation / reveal is a transform and must flatten.
